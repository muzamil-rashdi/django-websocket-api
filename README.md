# Django WebSocket API

Real-time chat API built with Django and Django Channels. The project demonstrates how an HTTP API and WebSocket connections can work together in a small, understandable service.

## Highlights

- Django application structure with a dedicated chat domain
- WebSocket-based real-time message delivery
- HTTP endpoints for application integration
- Docker Compose development setup
- Clear separation between application configuration and chat behavior

## Technology

Python, Django, Django Channels, WebSockets, ASGI, Docker, and a relational database.

## Run locally

Start the development stack with docker compose up --build, or run the Django development server after installing requirements.txt.

## Security note

This repository should contain only source and synthetic development data. Local databases, environment files, tokens, and credentials must remain ignored and must not be committed.
